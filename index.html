Transcription & résumé IA

Écho s'appuie sur Whisper pour la transcription et sur un modèle de langage pour rédiger le résumé. Une seule clé Groq gratuite couvre tout.

Clé API Groq

  1. Créez un compte gratuit sur console.groq.com — connexion Google ou GitHub, aucune carte bancaire.
  2. Ouvrez la page API Keys, puis « Create API Key ».
  3. Copiez la clé (elle commence par gsk_) et collez-la ci-dessous.

Rédaction IA du résumé

La rédaction utilise GPT-OSS 120B via Groq — la même clé que la transcription, aucun réglage supplémentaire. Le modèle peut être changé ci-dessous.

Modèle (modifiable)
La liste est lue directement depuis votre compte Groq. Note : les modèles Llama (Meta) sont restreints dans l'UE — GPT-OSS et Qwen y sont disponibles.
