Transcription & résumé IA

Écho s'appuie sur Whisper pour la transcription et sur un modèle de langage pour rédiger le résumé. Avec une seule clé Groq gratuite, tout est inclus : Whisper large-v3 pour la transcription, GPT-OSS 120B pour la rédaction. Z.ai, Qwen et OpenRouter sont aussi pris en charge ci-dessous.

Clé API Groq — transcription Whisper

  1. Créez un compte gratuit sur console.groq.com — connexion Google ou GitHub, aucune carte bancaire.
  2. Ouvrez la page API Keys, puis « Create API Key ».
  3. Copiez la clé (elle commence par gsk_) et collez-la ci-dessous.

Rédaction IA du résumé

Une fois la transcription faite, le modèle rédige un résumé complet : vue d'ensemble, plan en sections, notions définies, points à retenir — et décisions / actions pour les réunions. Les bavardages et conversations hors sujet sont ignorés. Avec Groq, votre clé Whisper est réutilisée automatiquement.

Modèle (modifiable)
La liste est lue directement depuis votre compte : seuls les modèles réellement accessibles y figurent. Note : les modèles Llama de Meta sont restreints dans l'Union européenne — GPT-OSS et Qwen, eux, y sont disponibles.

Application installable (PWA)

Sur Android (Chrome), ouvrez le menu ⋯ puis « Ajouter à l'écran d'accueil » : Écho s'installe comme une application autonome, avec son icône. En usage local (fichier ouvert directement), l'application fonctionne déjà hors ligne par nature.

Si vous hébergez cette page sur un serveur (GitHub Pages, etc.), placez le fichier sw.js téléchargeable ci-dessus à côté de la page : l'application pourra alors s'ouvrir sans connexion, avec une prise en charge hors ligne complète.
